# DA4 adapter: OMMX 2.6.1 / 3.0.0b5 benchmark results

2026年9月8日にDA4 API・求解を使用せず実施した比較です。両ブランチの全294測定が完了しました。

## 測定条件

- v2: `inspect_ommx_v2` / `43f4592e7e47a9595e6a227b3e8e041ab50dc142` / OMMX 2.6.1。
- v3: `inspect_ommx_v3` / `ff6a195118d7b3f124ae129f69df00381ce96c76` / OMMX 3.0.0b5。`update_ommx_v3`の`7808a6f`を取り込み。
- 環境: macOS-15.7.9-arm64-arm-64bit、arm64、論理CPU 8、Python 3.12.10。
- 共通依存: Pydantic 2.13.4、pydantic-core 2.46.4、NumPy 2.5.1、pandas 2.3.3、PyArrow 22.0.0、requests 2.34.2、memray 1.20.0。
- OMMXの依存構成は異なります。protobufはv2が5.29.6、v3が7.35.1で、v3には追加の依存もあります。全バージョンは各metadata.jsonに記録しています。
- 固定seed 0。decodeは決定的な実行可能状態1種類、frequency 16。16種類の解ではありません。energy等は合成値です。
- 時間: 初回＋warmup 3回後のrepeat 20回の中央値。計測区間ではGCを停止。
- メモリ: memrayで初回と2回目の追跡対象アロケーションのピークを測定。RSSではありません。
- 全測定を直列実行。各ケース・測定種別は新しいプロセス。v2の時間→メモリ、v3の時間→メモリの順。
- 生成・コピー・Policy生成・合成レスポンスの実行可能性検証は測定外。Preparationも`prepare`以外では測定外です。初回値も、このセットアップ後の最初の対象操作を表します。
- 両測定コミットの作業ツリーはclean。lockfileのSHA256、実行日時、Adapterバージョンはmetadata.jsonに記録。
- 比較率は`(v3 / v2 - 1) * 100`。負の値は時間またはメモリの減少です。小さい差や初回値は初期化・計測ノイズの影響を受けます。

| ブランチ | 時間条件 | メモリ条件 | 合計 |
| --- | ---: | ---: | ---: |
| v2 | 60 | 60 | 120 |
| v3 | 87 | 87 | 174 |
| 合計 | 147 | 147 | 294 |

## 結果の概要

- `instance-to-request`: 対応する30条件のうち、v3 directの中央値が小さい条件は27、2回目のメモリピークが小さい条件は22。時間変化の範囲は-43.9%〜+4.0%。
- `response-to-solution`: 対応する30条件のうち、v3 directの中央値が小さい条件は7、2回目のメモリピークが小さい条件は28。時間変化の範囲は-34.7%〜+51.9%。

これらはOMMXとAdapter実装の更新を含む、DA4 Adapterのv2/v3間のローカル処理比較です。OMMX単体の更新効果を切り分けた測定ではありません。求解性能・解の品質・通信を含むE2E性能、および他Adapterとの絶対値比較は評価していません。

## 検証と再現

- v2: pytest 95件成功。v3: pytest 119件成功。両方でdoctest、Ruff lint/format、AdapterとbenchmarksのPyrightが成功。
- 公開API用の新規モックテストは追加せず、`update_ommx_v3`の既存テストを取り込み。追加検証は合成レスポンス、frequency、定式化の同値性、測定条件の網羅性に限定。
- size 2/3 × seed 0/7の40ケースで、v2/v3の変数ID対応を戻したRequest数式を比較。二値変数の重複次数・ゼロ係数を正規化し、係数は許容誤差1e-10で一致。
- v3 direct/preparedの12組についても一致。size 2では全状態を列挙し、実行可能性・目的関数が一致。
- 既存の2026年8月25日レポートはbeta3・Preparation workload整合前の履歴です。今回の比較には使用していません。
- DA4のv2もOneHot hintsを利用するため、assignment/tspは両ブランチでregular/one-hotの両方を測定。

測定手順は[benchmarks README](README.md#再現可能な全件測定)を参照してください。生データには初回メモリも含め、全条件の値を保存しています。
